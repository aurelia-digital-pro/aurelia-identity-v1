# AURELIA Identity Generator — Quick MVP instructions

هذا ملف توثيق قصير يشرح كيفية تشغيل نسخة الـMVP المحلية المستندة إلى الملفات الثابتة في الفرع `mvp/local-backend-demo`.

ماذا يفعل هذا الفرع
- واجهة إنشأ هوية رقمية تعمل بالكامل في المتصفح (لا تحتاج لخادم).
- رفع الصور يتم تحويلها إلى Base64 داخل المتصفح ويتم تضمينها في الرابط الناتج.
- يمكن تصدير/استيراد بيانات الهوية كملف JSON لنسخ احتياطية أو لنقل إلى النظام الحقيقي لاحقًا.

تشغيل محلي سريع
1. انسخ المستودع أو انتقل إلى مجلد المشروع.
2. تأكد أنك على الفرع `mvp/local-backend-demo`:
   ```bash
   git fetch origin
   git checkout mvp/local-backend-demo
   ```
3. افتح `index.html` في المتص��ح مباشرة (أسهل طريقة) أو شغّل خادم ثابت:
   ```bash
   npx serve .
   # أو
   pnpm exec serve .
   ```
4. أنشئ الهوية عبر تعبئة الحقول ثم اضغط "أنشئ هويتي الرقمية الآن".
5. سيظهر رابط يحتوي البيانات (hash) — انسخه وشاركه.

تصدير واستيراد البيانات
- لتصدير: استخدم زر تنزيل البيانات (.json) في واجهة المنتجات.
- لاستيراد: استخدم زر استعادة البيانات (.json) واختر ملف JSON مُصدَّر سابقًا.

نقل البيانات إلى نظام حقيقي لاحقًا
- الملف المصدَّر يحتوي على حقول الصور كـ Base64. يمكنك استخدام سكربت صغير لتحميلها إلى S3 أو خادم، واستبدال الحقول بعناوين URL.

ملاحظات أمنية
- النسخة الحالية لا تحتوي على مصادقة ولا رفع آمن للصور؛ هي حل MVP للعرض فقط.
- لا تحفظ معلومات حسّاسة في هذه النسخة (رموز، كلمات مرور، بيانات مصرفية).

إذا أردت، أستطيع الآن:
- رفع هذه الملفات مباشرة إلى الفرع وإعداد Pull Request.
- أو إرسال بقية التعديلات هنا لتلصقها بنفسك.

اكتب "ارفع للريبو" لرفع التعديلات إلى الفرع `mvp/local-backend-demo` أو "أرسل الملفات هنا" للحصول على الملفات كاملةً في المحادثة.
